# 挥杖回位与三档质量对照 / Staff loop and three quality settings

Voxyz 对同一角色做了三档 GIF 输出对照，动作从挥杖、散出火花到回到初始姿势。作者描述了动作幅度与脸部线条清晰度之间的取舍。 [作者原帖](https://x.com/Voxyz_ai/status/2118750260549796019)
