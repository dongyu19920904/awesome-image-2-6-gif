# 草图到上色的三秒循环 / A three-second sketch-to-color loop

[中文首页](../README.md) · [English home](../README.en.md) · [作者动画预览](https://x.com/iijima_no6/status/2118169220596772927)

iijima 用一张草图做从勾线到上色的循环。作者报告结果为 12 帧、3 秒，并指出画笔和调色盘是模型自己补出的元素。 [作者动画预览](https://x.com/iijima_no6/status/2118169220596772927)

## 输入与原词 / Input and prompt

用有权使用的草图对照作者的动画预览，观察线稿、上色到结束这三个阶段。原帖描述了作者的 API 输出，完整提示词未公开。 [作者动画预览](https://x.com/iijima_no6/status/2118169220596772927)

## 微信下一步 / WeChat next step

想保留原作设定时，逐段查看循环中是否出现没要求的道具。若用于聊天，先检查主体在小尺寸下是否仍清楚。 [检查与适配](../guides/wechat.md#prepare)

## English

The creator reports a 12-frame, three-second API loop from rough sketch to finished color. Their example illustrates both progression and an unexpected addition of a brush and palette. The full prompt was not shared. [Source and method](https://x.com/iijima_no6/status/2118169220596772927)
