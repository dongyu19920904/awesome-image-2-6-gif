紫色怪兽眨眼、挥手并原地跳。上游原词明确要求保留不规则手绘线条和身体比例，让横线纸静止。

## 输入与原词 / Input and prompt

先读第 64 条的英文原词，再看上游统一附加的循环要求。作者用文字描述纸上涂鸦的效果。若从自己的手绘照片出发，可把纸纹、笔迹、线条和比例分开检查，再看角色动作有没有带动背景。 [完整原词](https://github.com/ailingqu/awesome-ai-gif-prompts/blob/a20f88b18a9abe8cd1531fb8a8e738a5a4701ce2/README.md#64-doodle-monster-comes-alive) · [统一循环要求](https://github.com/ailingqu/awesome-ai-gif-prompts/blob/a20f88b18a9abe8cd1531fb8a8e738a5a4701ce2/README.md#how-these-gifs-are-made)

For a real sketch reference, use the result as a comparison for keeping the drawing style and background stable.
