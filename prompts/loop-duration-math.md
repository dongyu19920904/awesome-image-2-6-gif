# 用帧数和帧时长算循环 / Calculate loop duration from frame timing

[中文首页](../README.md) · [English home](../README.en.md) · [作者实测](https://x.com/Superboy4949/status/2118785150368743814)

Superboy 用同样的 120 毫秒帧时长比较两次输出。作者报告 8 帧循环为 0.96 秒，16 帧为 1.92 秒。可以用帧数乘以每帧时长检查自己的目标。 [作者实测](https://x.com/Superboy4949/status/2118785150368743814)
