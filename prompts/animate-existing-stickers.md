# 让已有表情图动起来 / Animate existing sticker art

[中文首页](../README.md) · [English home](../README.en.md) · [作者试验与效果](https://x.com/AXIS95277/status/2118264145824944558)

AXIS 实验室把九张已有表情图逐张作为输入，记录用 GIF API 生成动图的试验。重点是保留角色、构图和原图上的字，再给每张图指定一个动作。 [试验原帖](https://x.com/AXIS95277/status/2118264145824944558)

## 输入与原词 / Inputs and prompts

准备有权使用的现有表情图。模板与九条动作写在独立回复里，适合按图替换动作。作者另给了不传参考图的对照，本卡聚焦已有表情的图转 GIF 路线。 [原词与九句动作](https://x.com/AXIS95277/status/2118264156885221681)

## 微信下一步 / WeChat next step

在聊天尺寸下检查原字是否清楚，再决定直接添加还是做专辑适配。原帖记录的是作者 API 试验。 [聊天与适配](../guides/wechat.md#prepare)
