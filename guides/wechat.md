# 从 GIF 到微信 / From GIF to WeChat

[中文首页](../README.md) · [English home](../README.en.md)

<a id="chat"></a>

## 聊天添加 / Add for chat

先将自己有权使用的动图保存到手机，参考作品方的自定义表情添加示例。菜单位置随客户端版本可能变化。个人添加与表情商店专辑投稿使用不同入口。 [雅马哈中国的添加示例](https://www.yamaha.com.cn/news_events/show_gsxw.html?id=1084)

Save a GIF you have permission to use, then follow the custom-sticker workflow in your current WeChat app. [Creator's illustrated example](https://www.yamaha.com.cn/news_events/show_gsxw.html?id=1084)

<a id="prepare"></a>

## 检查与适配 / Check and prepare

先看循环接缝、文字清晰度、浅色和深色背景的边缘。遇到体积或尺寸问题，按目标用途对照微信公开规范，再决定是否缩放、减色或减少重复帧。 [微信制作规范](https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/makingSpecifications#specifications_stickers) · [Ezgif 优化说明](https://ezgif.com/optimize) · [作者的去白边案例](../prompts/tibetan-fox-dark-mode.md)

Review the loop, caption, and edges at chat size. For store submissions, check current platform requirements before preparing the album files. [Official guidelines](https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/makingSpecifications#specifications_stickers)

<a id="submit"></a>

## 专辑投稿 / Submit a pack

先确认开放平台账号入口和审核标准。按官方清单准备主图与配套材料，再参考零点 Drift 的上传对照和提审物料提示词。作者报告的上架状态见案例页。 [开放平台](https://sticker.weixin.qq.com/) · [审核标准](https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/auditingStandards#auditingStandards_demand) · [提审案例](../prompts/ginger-cat-and-capybara.md)

Read the official guidelines and then use Drift's follow-up for a creator's example of matching GIFs, labels and album assets to submission fields. [Creator's submission example](../prompts/ginger-cat-and-capybara.md)

更多旧版教程和核查日期见现有目录。 [微信完整资料](https://github.com/dongyu19920904/awesome-gif-stickers/blob/v0.3.3/docs/wechat.md)
